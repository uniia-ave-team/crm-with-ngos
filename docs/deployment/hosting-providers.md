# Провайдери та розміщення даних

## Критерії вибору

Для CRM потрібен віртуальний сервер (VPS) із підтримкою Docker. Практично будь-який
провайдер, що надає VPS на KVM-віртуалізації з Ubuntu, підходить. При виборі
варто звернути увагу на:

- **Резервне копіювання сервера** (знімки або автоматичні копії) — для
  інсталяцій рівня 1 це основний спосіб зберігати копію за межами сервера.
- **Шаблон із попередньо встановленою панеллю** (Dokploy, Portainer) — дає
  змогу обійтися без терміналу; саме на цьому побудований рівень 1.
- **Розташування дата-центру** — див. розділ про розміщення даних.
- **Підтримка українською** — має значення, якщо адмініструванням займатиметься
  людина без технічної підготовки.

## Панелі керування

Панель дає керування контейнерами через браузер: перегляд журналів,
перезапуск, оновлення.

| Панель                            | Особливості                                                                    |
| --------------------------------- | ------------------------------------------------------------------------------ |
| [Dokploy](https://dokploy.com)    | Використовується в інструкції рівня 1. Власний реверс-проксі (Traefik) із сертифікатами Let's Encrypt, розгортання з Git, близько 350 МБ пам'яті |
| [Portainer](https://www.portainer.io) | Керування стандартним `docker-compose.yml` без змін; описано в рівні 2. Безкоштовна версія не підтримує відносні шляхи в стеках з Git; файл продукту не має таких залежностей |
| [Coolify](https://coolify.io)     | Аналог Dokploy з більшою функціональністю та керуванням кількома серверами; потребує близько 4 ГБ пам'яті |

Для панелей із власним реверс-проксі використовується
`deploy/docker-compose.dokploy.yml` — див. [server.md](server.md#dokploy).

## Керовані платформи

Сервіси, що самі надають сервер і приймають Docker Compose: Elestio, Zeabur,
Railway, Sevalla. Розгортання займає хвилини і не потребує адміністрування.
Вартість вища за VPS, а перенесення даних на власний сервер згодом складніше.
Перед вибором перевірте, як експортувати дамп PostgreSQL із платформи.

## Розміщення даних

CRM зберігає персональні дані: бенефіціарів, донорів, працівників, партнерів.
При виборі розташування сервера враховуються два чинники.

**Правові вимоги.** Закон України «Про захист персональних даних» та, за
наявності європейських партнерів або донорів, вимоги GDPR у договорах. Окремі
донори вимагають зберігання даних у ЄС; такі умови варто з'ясувати до вибору
провайдера.

**Фізичні ризики.** Дата-центри в Україні вразливіші до пошкоджень
інфраструктури та тривалих відключень електроенергії, ніж дата-центри в ЄС.

Рекомендована схема: основна інсталяція розташовується там, де цього вимагають
договірні зобов'язання; резервні копії зберігаються в іншій юрисдикції та в
іншого провайдера. Копія на тому самому сервері або в того самого провайдера
не захищає від жодного з описаних ризиків.
