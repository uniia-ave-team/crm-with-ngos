Сайт зібраний на [Starlight](https://starlight.astro.build) і
публікується на GitHub Pages після кожного злиття в `main`, яке змінює
`docs/` або контракт API.

## Локально

```bash
just docs          # http://localhost:4321/crm-with-ngos/
just docs-build    # збірка, як у CI
```

Сторінки — Markdown або MDX у `docs/src/content/docs`. Структура папок
визначає адреси й бокове меню; порядок у меню задає `sidebar.order` у
frontmatter. Кожна сторінка має посилання «Редагувати сторінку», яке
відкриває файл на GitHub.

Пишемо українською. Назви команд, файлів, класів і фрагменти коду
залишаються як у коді.

## Довідник API

Сторінка `docs/public/api/index.html` показує `openapi.json` через
[Scalar](https://scalar.com). Під час збірки `openapi.json` і бандл Scalar
копіюються поруч зі сторінкою (`npm run prepare:api`), тому довідник
завжди відповідає закоміченому контракту. Редагувати його окремо не
потрібно — достатньо [оновити контракт](../api-contract/).

## Архітектурні рішення

Рішення, які важко змінити пізніше, записуються в розділ
[Архітектурні рішення](../../decisions/0001-monorepo/): файл
`docs/src/content/docs/decisions/NNNN-short-name.md` з наступним номером.

```markdown
---
title: "0004: Коротка назва рішення"
sidebar:
  order: 4
---

**Статус:** прийнято · **Дата:** РРРР-ММ-ДД

## Контекст
Яку проблему розв'язуємо, які обмеження.

## Рішення
Що обрали.

## Наслідки
Що стає простіше, що складніше, що доведеться зробити.
```

Прийняте рішення не переписують. Якщо воно змінюється, додають нове з
посиланням на попереднє, а в старому змінюють статус на «замінено».
