## Що потрібно зберігати

| Що                     | Де                                                     | Без цього                                   |
| ---------------------- | ------------------------------------------------------ | ------------------------------------------- |
| База даних             | Том PostgreSQL                                         | Втрачаються всі дані                        |
| Завантажені файли      | Том API `/data/uploads`                                | Зникають аватари, логотип, зображення сторінки входу |
| Налаштування           | Змінні середовища або `.env` інсталяції                | Не вийде запустити систему з тими самими ключами |
| Службові ключі         | Том API `/home/app/.aspnet/DataProtection-Keys`        | Перестають діяти вже надіслані одноразові посилання, наприклад для скидання пароля |

Базу й файли копіюють разом: у базі зберігаються назви файлів, тож копія
бази без відповідних файлів дасть порожні аватари й логотипи. Логи
(`/data/logs`) зберігати не обов'язково.
