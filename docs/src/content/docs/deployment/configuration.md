## Як задаються параметри

CRM складається з трьох контейнерів: база PostgreSQL, API і вебклієнт.
Налаштування потребує лише API, і задається воно змінними середовища
контейнера, наприклад у `docker-compose.yml` або файлі `.env`.

Назва змінної — шлях до параметра через два підкреслення:
`FileStorage__BaseUrl`. Елементи списку нумеруються з нуля:
`CorsSettings__AllowedOrigins__0`, `CorsSettings__AllowedOrigins__1`.

Вебклієнт налаштувань не має: адресу API він визначає сам. За
замовчуванням це порт 5065 того самого домену, з якого відкрито сторінку;
іншу адресу користувач може ввести на сторінці входу.

## Обов'язкові параметри

| Змінна                                    | Опис                                                           |
| ----------------------------------------- | -------------------------------------------------------------- |
| `ConnectionStrings__PostgreSqlConnection` | Підключення до бази: `Host=db;Port=5432;Database=crm;Username=crm;Password=...` |
| `JwtOptions__Secret`                      | Ключ підпису токенів входу: випадковий рядок від 32 символів   |
| `FileStorage__BaseUrl`                    | Публічна адреса API, з якої браузер завантажує файли: `https://crm.example.org:5065` |
| `CorsSettings__AllowedOrigins__0`         | Адреса, з якої відкривають вебклієнт: `https://crm.example.org` |

Без підключення до бази або ключа підпису API не запуститься. Без двох
інших він запуститься із значеннями для локальної розробки
(`http://localhost:...`), але вебклієнт з іншої адреси не зможе до нього
звертатися, а посилання на файли будуть вести на `localhost`.

## Додаткові параметри

| Змінна                                  | Опис                                              | За замовчуванням |
| --------------------------------------- | ------------------------------------------------- | ---------------- |
| `JwtOptions__AccessTokenExpiryMinutes`  | Термін дії токена доступу, хвилин (1–60)          | `15`             |
| `JwtOptions__RefreshTokenExpiryDays`    | Скільки днів діє вхід без повторного введення пароля | `7`           |
| `JwtOptions__InvitationTokenExpiryHours` | Термін дії запрошення, годин                     | `48`             |
| `IdentityOptions__RequiredLength`       | Мінімальна довжина пароля                         | `8`              |
| `RateLimiting__PermitLimit`             | Запитів з однієї адреси за вікно                  | `50`             |
| `RateLimiting__WindowInSeconds`         | Тривалість вікна, секунд                          | `1`              |
| `SerilogOptions__RetainedFileCountLimit` | Скільки днів зберігати загальний лог             | `5`              |
| `SerilogOptions__RetainedErrorFileCountLimit` | Скільки днів зберігати лог помилок          | `31`             |

## Дані на диску

Образ API зберігає дані в теках, які треба змонтувати як томи, інакше
вони зникнуть разом з контейнером:

| Тека в контейнері                        | Що в ній                                          |
| ---------------------------------------- | ------------------------------------------------- |
| `/data/uploads`                          | Завантажені файли: аватари, логотип організації, зображення сторінки входу |
| `/data/logs`                             | Файли логів                                       |
| `/home/app/.aspnet/DataProtection-Keys`  | Службові ключі шифрування                         |

База зберігає дані у власному томі контейнера PostgreSQL
(`/var/lib/postgresql/data`).

## Безпека

- `JwtOptions__Secret` і пароль бази — унікальні для кожної інсталяції;
  не використовуйте значення з `compose.yaml` репозиторію.
- Зміна `JwtOptions__Secret` завершує всі активні сеанси.
- Вебклієнт і API мають бути доступні через HTTPS. Сторінка, відкрита
  через HTTPS, не може звертатися до API через HTTP: браузер заблокує такі
  запити.
- API довіряє заголовкам `X-Forwarded-For` і `X-Forwarded-Proto`, тому
  його порт має бути доступний лише через зворотний проксі.

## Скидання пароля адміністратора

Якщо адміністратор забув пароль і ніхто інший не може видати йому
посилання для скидання, пароль змінюють на сервері утилітою, яка входить в
образ API:

```bash
docker compose exec api crm reset-password -e admin@example.org
```

Утиліта двічі попросить новий пароль, змінить його й завершить усі сеанси
цього користувача. Пароль має відповідати політиці паролів API.
