# Крок 4. Сайт документації — план реалізації

> **Для агентів:** виконується в гілці `docs/site` (відгалужена від `main`).
> Кроки позначаються чекбоксами (`- [ ]`).

**Мета:** документація для розробників — сайт Starlight на GitHub Pages з
довідником API, який будується із закоміченого `openapi.json` і
публікується після злиття в `main`.

**Spec:** [`../specs/2026-10-02-devops-and-docs-design.md`](../specs/2026-10-02-devops-and-docs-design.md),
розділ 5.

**Стек:** Astro 7.3, Starlight 0.42, `@scalar/api-reference` 1.72,
`actions/upload-pages-artifact` v5, `actions/deploy-pages` v5.

## Глобальні обмеження

- Мова сайту — українська; назви з коду лишаються як у коді.
- Кожне твердження про архітектуру перевірене за кодом.
- Довідник API не редагується вручну.
